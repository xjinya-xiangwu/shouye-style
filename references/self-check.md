# 交付前自检清单

量化部分交给脚本，技法与红线部分人工过一遍。

```bash
python scripts/check_draft.py <草稿路径>
```

---

## A. 量化指标（脚本执行）

脚本会输出这 9 项，全部 OK 才进入下一关：

| 指标 | 目标区间 |
|---|---|
| 汉字数 | 3000 ~ 4500 |
| 段落数 | 90 ~ 110 |
| 段落长度中位数 | 26 ~ 38 |
| 短段落（≤15字）占比 | 20% ~ 30% |
| 句长中位数 | 18 ~ 30 |
| 数字密度 | 8.0 ~ 12.0 /千字 |
| 冒号甩段 | 12 ~ 18 次 |
| 章节数 | 3 ~ 6 |
| 末行字数 | 4 ~ 30 |
| 感叹号 | ≤ 3 个 |

**注意**：短篇（<2500 字）按比例折算，不要为了凑指标注水。

---

## B. 技法清单（逐条打勾）

**结构**
- [ ] 开头第一段落到具体时间 + 地点 + 画面
- [ ] 开头没有出现「近年来」「众所周知」之类的铺垫
- [ ] 章节之间用裸数字分隔
- [ ] 结尾回到开场的意象或物件，形成闭环
- [ ] 末行 ≤30 字，且没有感叹号

**数据**
- [ ] 每个核心论点都挂了至少一个具体数字
- [ ] 数字是颗粒化的（写「2.3 亿」而不是「一大笔钱」）
- [ ] 没有出现无法追溯来源的数字

**引语**
- [ ] 关键对话用了「冒号 + 换行 + 引语独立成段」
- [ ] 引语是真实说过的（真实选题）或明确标注为虚构（练习稿）

**节奏**
- [ ] 长句之后有短句换气
- [ ] 关键判断和转折单独成段，≤15 字
- [ ] 全篇没有连续三段以上都是长段落

**视角**
- [ ] 至少有一处第一人称在场证据（我去看过 / 他跟我说 / 有人给我看过）
- [ ] 叙述者没有站到道德高地上宣判
- [ ] 判断交给数字、引语、典故，而不是形容词

---

## C. 红线清单（任何一条不过，不交付）

- [ ] **真实选题**：每个人名、数字、时间、地点都可核查；不能核实的已删除或标注「据公开报道」
- [ ] **真实人物**：只写了已公开证实的事实；没有动机推定、道德审判、侮辱性措辞
- [ ] **敏感议题**：未涉及公共政策、司法个案、民族宗教、领土主权等议题的对外成稿
- [ ] **版权**：没有复制、改写、续写任何兽楼处原文；示例为原创
- [ ] **署名**：没有使用「兽爷」「兽楼处」或任何暗示原作者身份的名义
- [ ] **虚构标注**：练习稿开头或结尾标注「本文为虚构题材的文体练习」及其虚构部分

---

## 常见失败模式

| 症状 | 病因 | 改法 |
|---|---|---|
| 读起来像通稿 | 数字太少、形容词太多 | 补数字，删形容词 |
| 节奏拖沓 | 段落太长、没有短段重音 | 把关键判断拆成独立短段 |
| 像在说教 | 作者直接下判断 | 删掉判词，换成数字或引语 |
| 结尾泄气 | 末行太长或抛了新论点 | 末行压到 30 字内，回到开场意象 |
| 情绪过火 | 感叹号太多、形容词过猛 | 删感叹号，改用事实陈述 |
| 空洞 | 全是宏大叙述没有具体人 | 加入一个具体的人 + 一句他说过的话 |
