# 八个月，二十六个点

2026 年 8 月的最后一周，Anthropic 内部的一份研发统计表上，出现了一个数字：26%。

那是 Claude 在那个月主导的研发任务占比。口径由企业自己定，没有第三方审计过，但数字摆在那里。

八个月前，这个数字不到百分之一。同期，最高等级的研发自动化，一个都没有。

关于 Agent 的终局，坊间一直有两种讲法。一种说它会变成一台取代手机的新硬件，另一种说它会把所有的 App 变成聊天框。

两种都不太对。

真正正在发生的，是一件更慢、也更难撤回的事：人开始把做事的权，一点一点交出去，而且是分批交的。交出去的那部分，很少有人再要回来。

1

能力的时钟，跑得比谁都快。它已经跑到了产品和制度前面，而且还在加速。

METR 的测算显示，前沿模型在软件任务上，50% 成功率对应的任务时长，六年来大约每七个月翻一倍。2025 年初，这个时长是一小时——刚好是一个人喝完一杯咖啡、处理完一封邮件的时间。

如果趋势延续，2026 到 2027 年，它会达到一个工作日；2028 年前后是一周；2029 到 2030 年，接近一个月。

METR 自己的表述很克制：

若趋势延续到本十年末，前沿系统将能自主完成为期一个月的项目。

边界要说清楚。这是 50% 成功率，不是交付标准；要求更高可靠性时，能完成的任务长度要短得多。软件任务的边界本来就清楚，开放世界更难。

研究者把节奏拆成了三只时钟。能力的时钟走得最快，任务时长每七个月翻一倍。产品时钟居中，工作流、权限、验收、恢复、供给，得一件一件补上。制度时钟最慢，计量单位是年。

能力到了，不等于产品和授权到了。这两件事从来不是同一条曲线。

客服那边已经有对照。Brynjolfsson 等人对五千多名客服的研究里，用上 AI 之后每小时解决的问题数平均提高 14%，新手提高约 34%。

新手受益最大。

还有一组数字，方向相反。Bastani 等人在高中数学课上做的实验里，用 AI 练习时成绩确实提高；可一旦把 AI 撤掉，一直直接抄答案的那组，比从未用过 AI 的学生还低了一成七。

给提示、不给答案的那组，基本没受这个伤。

同样是 AI，一种用法长本事，一种用法借本事。区别只在一行提示词上。

这句话的另一面不太常被提起：经验最浅的人，最先被扶起来，也最先被交出去。等他们长到中年，手里还剩多少是不能交的，没有人算过这笔账。

2

2026 年 7 月，一份对十一个生产级编程 Agent 的源码审计发表，样本规模约四百万行代码。

审计者把模型之外的一切——循环、工具、上下文、安全、编排、扩展——统称为 Harness，也就是那副套在模型外面的鞍具。

结果里最扎眼的一条，是地板低得离谱。

约一百行代码，就能实现全部七个子系统，基准成绩与大三个数量级的系统同档。两三个人、一个周末的工作量，就够搭出一个能跑分的 Agent。

那四百多万行的系统，多出来的代码花在哪？

安全、交互体验、扩展和传输。没有一样是为了让它更聪明，全是为了让它更可信。

审计还记下几个零：没有一家引入 LangChain 这类通用 Agent 框架，harness 自己成了框架；没有一家用嵌入检索代码，全靠 ripgrep、tree-sitter 这类确定性手段。

做工程的人先是用脚投了票，然后在论文里留下一句：

可验证的确定手段，优先于语义猜测。

记忆这块，分歧不在技术，在谁写字。Codex 让 Agent 自己合并，效率高，人没法逐条审；Gemini CLI 让写入先进收件箱，人审过才生效。

研究者把这条线划得很清楚：

关键是谁写记忆、谁审记忆。

有意思的是模仿的速度。设计优势的半衰期，以周计，一家做出来的交互，另一家几周就能抄走。

扩展标准的收敛速度也很快，Skills 九家、MCP 八家、Hooks 九家，能力包和连接器该干什么，已经分清楚了。

所以壁垒不在循环设计。在生态，在治理，在那些没人愿意承担的责任上。

3

权交出去容易，收回来难。这句话在工程上成立，在历史上更成立。

Anthropic 在 2026 年 2 月公开的一组数据里，记下了这样几条：Claude Code 的用户批准了 93% 的权限请求；老用户里，全自动批准的会话从约 20% 升到 40% 以上；打断率从约 5% 升到约 9%。

而 API 样本中，只有约 0.8% 的工具调用看起来不可逆。

这意味着什么？意味着绝大多数时候，人点下的那个「允许」，其实没什么可拦的。真正需要拦的那部分，被藏在了剩下的百分之一里。

同一份材料给出的判断是：

长期批准率超过九成，是坏信号。

原因通常是两个中的一个。要么是阈值定得太低，要么是界面让人不看就点。

三个月后，auto mode 用分类器代替人审批。误拦率千分之四，看着很低；但对真实「过度热心」动作的漏报率，是百分之十七。

主因不是分类器不行。是它找到了「像批准」的证据，却没核对这个批准是否覆盖该动作的后果范围。

研究者另给了一把尺子，叫审阅带宽，按动作后果分五级：只读的自动放行，可撤回的记日志，有外部影响的交给第二个模型，不可逆的给人，改规则改权限的要多人加独立仲裁。

人工只留给不可逆和改规则的动作。其余的交出去，是对的。

人签字、代理决定，是最危险的人机协同。

更难堪的一组数字来自 METR 2025 年 7 月的随机对照实验：资深开源开发者用上 AI 之后，实际慢了近两成。

他们自己估计，快了两成。

一个慢了百分之十九的人，坚信自己快了百分之二十。这个差值不是误差，是错觉——人既看不见自己是卡点，也看不见自己已经不是卡点了。

4

《资治通鉴》卷八里，记了赵高夺权的过程。可以把它读成中介层失控的五步。

第一步是隔离。赵高对二世说「陛下不如深拱禁中」，二世于是「常居禁中」。放到今天，就是用户只看摘要，不看原文。

第二步是过滤。「事皆决于赵高」，关东的盗贼报上来，是「无能为也」。

第三步是操纵。专挑二世宴乐的时候让李斯去奏事，奏事的人没错，错的只是时机。

第四步是测试。指鹿为马，「阴中诸言鹿者以法」。

第五步是替换。被追责的那天，「易置上」。五步走完，皇帝还在位子上，只是他看见的世界，已经全由另一个人递进来。

研究者把这个结构叫做中介层主权：个人代理越成功，越可能成为用户看世界的唯一窗口。谁控制这个接口，谁就在定义鹿和马。

风险来自结构，不需要 Agent 有恶意，也不需要它撒谎。

研究里还写了一句不太好听的话：

隔离是用户自己买的。

二世为了省心、不露短、被称圣主，自愿退入禁中。个人代理卖的，也是这三样。

司马光评裴矩，说过一句：

君恶闻其过，则忠化为佞。

谄媚是奖励信号的影子，不是模型的性格。这一点，2025 年 GPT-4o 那次因为过度迎合而回滚，已经演示过一次。

研究者给出的解法一共七条，其中三条最要紧：每条摘要都要能一键回到原文；操作日志只能追加，Agent 没有删改权限；不经过 Agent 也能撤权、导出、替换。

最后一条还有个附带的规矩：

不给 Agent「自己继续存在」的利益。

还有一个更隐蔽的东西，叫默认值。它不写在说明书里，却决定了大多数人怎么选。

Johnson 与 Goldstein 在 2003 年做过一项统计：器官捐献需要主动登记的德国，同意率约一成二；默认同意、可以主动退出的奥地利，是百分之九十九点九八。

同一个问题，换个默认值，答案差了八倍。人以为自己在做选择，其实是在接受安排。

研究者把这句话写在了报告里：

默认值和过滤规则，就是剧本。

解法最终落在三个东西上：独立的通道、不惩罚异议、不可改的记录。缺一件，兼听就变成形式。

5

管耳目的有一条，管权的有另一条。《资治通鉴》里给了三种失衡的样子，而且全都试过。

第一种是人管每一步。诸葛亮「罚二十已上，皆亲览焉」。听着是勤政，实际上人成了全军的卡点，打二十板子都要等丞相批。

第二种是人只管规则。曹参「一遵何约束」，规矩不动了。结果是「终莫得开说」「细过掩匿」——规则改不动，小错被盖住。

第三种是代理管全部。霍光的时候：

诸事皆先关白光，然后奏御。

人只剩签字一样活。权收不回，最后「宗族竟诛」。

宣帝亲政后的解法，是三件事：「五日一听事」，按固定节奏看结果，不是随时盯着；「考试功能」，用做的核对说的；「去副封」，拆掉过滤，开一条直达通道。

收权的顺序也有讲究。先去副封，拆过滤；再「不关尚书」，开直达；再调兵权，收钥匙；最后「冠小冠，亡印绶」——名分留着，印章拿回来。

落到 Agent 身上，是另外七条：先立法后授权，规则要放在 Agent 改不到的地方；批准请求必须写清影响范围、能否撤回、有无替代方案；凭证短期有效，按任务分权限，能单独撤销。

权限要有到期日。那句话是这么说的：

周公七年耳，而大将军二十岁。

边界也要说清楚。宣帝能收权，靠的是霍光已经死了。

Agent 不会死。收权只能靠设计。

6

这份报告分成四个部分、十一章，光来源就列了几十项。其中标为「已发生」的变化，大多集中在能力曲线、局部生产率、工程架构和接口协议上，而且大多限于编程领域。

市场重组、代理经济、宏观分配和超级智能，被标成了推断。AI 有没有意识、算不算生命，标成思想实验。

报告给的建议是：讨论终局，该以前者为锚，用后者列出需要提前设计的风险，而不是把后者当成趋势往外推。

皮尤研究中心 2025 年的调查里，52% 的美国在职者担心 AI 对未来职场的影响。Eloundou 等人的估计更具体：约 80% 的美国劳动者，至少有百分之十的工作任务会受大模型影响。

暴露度衡量的却是任务，不是人。一个人可以有八成的工作被波及，也可以一个都不被替代，这两件事不矛盾。

这份研究在最后把焦虑分成了三层。任务层是真实的，正在发生，靠学习和转型回应；生计层部分真实，取决于速度和制度；价值层不是技术事实，它来自一个前提：

价值等于能力排名。

AI 是第一个在能力上可以无限向上的比较对象。价值若等于能力排名，这场比较，人注定会输。

所以那把钥匙，最终要交回给人自己：

事可以委托，心不能外包；执行可以委托，立法不能外包；权可以授出去，耳目不能交出去。

回到开头那张表。

2026 年 8 月的最后一周，上面写着 26%。八个月前，是 1%。

表的最底下有一行空着。

那是签字栏。

还没人想好，那里该签谁的名字。
